# BhashaSaathi V23 Product-Ready Changes

- English is the default/main lesson source language.
- Hindi and Marathi are optional target languages.
- Optional translations are never required for Activities or Publish.
- Source language is persisted on the lesson and remains the authoritative original.
- Selected target languages are remembered per lesson in local browser storage.
- Practice generation is manual/on-demand; approval no longer auto-starts heavy background work.
- Lesson TTS is manual/on-demand and never blocks Publish.
- Live Translate defaults to English -> Hindi and remembers the last source/target pair.
- Live session history already stores the source and target language for every session.
- Publish only requires a valid original lesson source.

The RTX 2050 benchmark remains: 30.2s audio / 116.12s generation. The product therefore does not perform Parler generation during Publish.
